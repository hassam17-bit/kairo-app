# Kairo — Personal Life Management App

Kairo is an Android productivity application designed to help users organize daily activities, manage routines, and plan their time more effectively.

Built using React Native and Expo with an AI-assisted development workflow.

## Features

- Daily planning and task management
- Routine and schedule organization
- Prayer-time integration
- Productivity-focused interface

## Technologies

- React Native
- JavaScript
- Expo
- Expo Application Services (EAS)

## Development

This project was developed using AI-assisted software development, combining product planning, interface design, testing, debugging, and iterative improvements.

## Getting Started

1. Install Node.js.
2. Clone or download this repository.
3. Run `npm install`.
4. Run `npx expo start` to launch the development environment.

## Android APK

Android builds can be created using Expo Application Services (EAS).
